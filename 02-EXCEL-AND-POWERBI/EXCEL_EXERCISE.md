# Excel and Power BI practical exercise

Use `09-PRODUCTS/Pharma-Stock-Intelligence/data/synthetic_stock.csv`.
1. Import as an Excel Table.
2. Set expiry_date to Date; quantity and reorder_level to Whole Number.
3. Add DaysToExpiry using the analysis date.
4. Classify each batch as expired, near expiry (0–90 days), or normal.
5. Calculate total units, expired units, near-expiry units and low-stock batch count.
6. Build a PivotTable by category and a bar chart.
7. Repeat the import and cleaning in Power Query, then build a Power BI report.

Define every KPI clearly. Do not calculate days-of-cover without trustworthy usage history.
