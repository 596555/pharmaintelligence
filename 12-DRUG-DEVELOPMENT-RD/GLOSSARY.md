# Pharmaceutical manufacturing, development and discovery glossary

| Term | Meaning |
|---|---|
| API / Drug substance | Active pharmaceutical ingredient before incorporation into the finished drug product |
| Drug product | Finished dosage form containing the drug substance and other formulation components |
| Excipient | Formulation component other than the active ingredient, used for a defined function |
| GMP | Good Manufacturing Practice requirements and controls for medicinal-product manufacture |
| QTPP | Quality Target Product Profile |
| CQA | Critical Quality Attribute |
| CMA | Critical Material Attribute |
| CPP | Critical Process Parameter |
| QbD | Quality by Design: systematic development based on predefined objectives and product/process understanding |
| CMC | Chemistry, Manufacturing and Controls |
| DoE | Design of Experiments |
| CAPA | Corrective and Preventive Action |
| Deviation | Departure from an approved instruction, procedure or expected condition requiring documented assessment |
| Technology transfer | Structured transfer of product/process knowledge and controls between development, pilot and manufacturing settings |
| Process validation | Documented evidence that a process can consistently deliver output meeting its defined requirements |
| Stability-indicating method | Analytical procedure capable of assessing relevant changes in a product over time |
| TPP | Target Product Profile |
| ADME | Absorption, Distribution, Metabolism and Excretion |
| DMPK | Drug Metabolism and Pharmacokinetics |
| SAR | Structure–Activity Relationship |
| Hit | A confirmed assay-active starting point from a screening process |
| Lead | A compound series with evidence supporting further optimization |
| QSAR | Quantitative Structure–Activity Relationship |
| Cheminformatics | Computational handling and analysis of chemical structures and related data |
| Applicability domain | Region of chemical/data space where a predictive model has adequate support to be used cautiously |

This glossary is for learning. Interpret terms using current applicable ICH, WHO, FDA, EMA and national guidance.
