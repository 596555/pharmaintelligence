# Low-risk pharmacy administration automation

Prepare a draft expiry/reorder review file from an approved synthetic or authorized stock export.

1. Select a CSV file.
2. Validate required columns, dates, numeric ranges and duplicate batch IDs.
3. Calculate administrative review flags.
4. Preview exceptions and source filename.
5. Require human review and approval.
6. Export a draft CSV; do not send orders or messages automatically.

Never automate prescribing, dispensing, dose changes, therapy recommendations or patient-specific decisions. Preserve original values and flag ambiguous records rather than silently correcting them.
