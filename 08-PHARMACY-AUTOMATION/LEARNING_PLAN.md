# Pharmacy Operations and Automation

Learn process mapping, low-risk task selection, inputs/outputs, exception paths, human approvals, validation, audit logs and API basics.

## Candidate workflows
- Expiry report generation from approved stock exports.
- Draft reorder-list preparation for manager review.
- Medicine catalogue duplicate detection.
- Daily operational summary using synthetic data.

Automation must not prescribe, dispense, change doses, override clinical alerts or make patient-specific decisions. Require human approval.
