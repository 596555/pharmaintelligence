# الدورات المجانية والشهادات — PHARMAINTELLIGENCE

**سياسة الاختيار:** لا نعدّ الدورة مجانية الشهادة إلا إذا أكد الناشر ذلك. قد يكون المحتوى مجانياً بينما الشهادة مدفوعة، وقد تكون الشهادة إثبات إكمال وليست اعتماداً مهنياً أو ترخيصاً. تحقق من الشروط عند التسجيل لأن سياسات المنصات تتغير.

## ترتيب مقترح لك

1. Kaggle Python ثم Pandas ثم SQL.
2. IBM Data Fundamentals وAI Fundamentals.

5. بعد كل دورة، أنجز مشروعاً صيدلانياً في GitHub يثبت المهارة.

## كيف تسجل الدورة في محفظتك؟

أنشئ سجلاً يتضمن: اسم الدورة، الجهة، رابط التحقق من الشهادة، تاريخ الإكمال، عدد الساعات، المهارات، والمشروع الذي طبقت فيه ما تعلمته. لا تكتب "Certified" إذا كانت الوثيقة مجرد حضور أو إكمال؛ اكتب "Course Completion" بدقة.

**مهم:** الشهادات لا تعادل ترخيص مزاولة أو اعتماداً تخصصياً أو خبرة صناعية عملية. قيمتها تزيد عندما تقترن بمشروع قابل لإعادة التشغيل ومراجعة موثقة.
