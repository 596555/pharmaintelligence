# Applied Machine Learning Foundations

Learn train/validation/test separation, data leakage, classification vs regression, baselines, confusion matrix, precision, recall, calibration, imbalanced data, bias and explainability.

## Free resources
- Google ML Crash Course: https://developers.google.com/machine-learning/crash-course
- scikit-learn tutorials: https://scikit-learn.org/stable/tutorial/index.html

## Safe project ideas
Use synthetic inventory data to estimate stockout risk or classify records needing manual review. Do not train models to diagnose patients, recommend prescriptions or autonomously change therapy.
