# PHARMAINTELLIGENCE Web Lab

واجهة عربية موحدة تفتح في المتصفح، تجمع الأكاديمية، Python runtime، تحرير CSV/XLSX، SQLite، مصادر البحث العامة، كتالوج المنتجات والمكتبة.

## التشغيل

- افتح النسخة المنشورة عبر GitHub Pages بعد تفعيل Pages من إعدادات المستودع.
- أو افتح `index.html` محلياً للواجهة الأساسية. بعض وظائف المتصفح مثل service worker تتطلب localhost أو HTTPS.
- عند أول تشغيل، يلزم الإنترنت لتحميل Pyodide وSheetJS وsql.js والخطوط من CDN. Python runtime قد ينزّل عدة ميغابايتات.
- يفضل تشغيلها عبر GitHub Pages أو خادم static محلي؛ بعض المتصفحات تقيد fetch وملفات WASM عند فتح file:// مباشرة.

## ما الذي يعمل داخل المتصفح؟

| الأداة | طريقة الدمج | الحدود |
|---|---|---|
| Python | Pyodide / WebAssembly | لا يثبت Python المكتبي؛ توافق الحزم يختلف؛ runtime ينزل عند الطلب |
| Excel / CSV | SheetJS + جدول HTML قابل للتحرير | استيراد وتصدير وتعديل خلايا أساسي؛ ليس بديلاً كاملاً عن Microsoft Excel أو Power Query |
| SQL | SQLite عبر sql.js | قاعدة في الذاكرة، تزول عند تحديث الصفحة |
| البحث | openFDA / PubChem / RxNorm GET APIs | اتصال إنترنت وCORS وتوافر المصدر مطلوب |
| الأكاديمية | دروس واختبارات في الواجهة | تقدم محلي في localStorage لهذا المتصفح |

## التحقق

افتح أدوات المطور وتحقق من عدم وجود أخطاء تحميل CDN. اختبر Python بعد الضغط على تحميل بيئة Python، واستورد ملف XLSX تجريبياً، وهيئ SQL وشغل الاستعلام، ثم جرب PubChem. لا تستخدم بيانات حقيقية حساسة.

## النشر

يمكن نشر المجلد عبر GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root). بعد النشر استخدم رابط Pages الذي يظهر في الإعدادات.

## السلامة والخصوصية

- الملفات والجداول ونتائج Python وSQL تتم معالجتها في المتصفح ما لم تطلب أنت تنزيلها أو تستعلم من API خارجي.
- طلبات البحث ترسل عبارة البحث إلى المصدر العام المختار.
- لا ترفع بيانات مرضى أو بيانات صيدلية/مصنع سرية.
- بيانات FAERS لا تثبت السببية أو incidence. لا توجد قرارات علاج أو شراء أو إطلاق دفعات.
- صفحة الويب أداة تعليمية أولية وليست نظاماً منظماً أو متحققاً للاستخدام السريري/GMP.

## مكونات مستقبلية وليست مدمجة بعد

لا تتضمن النسخة الحالية Microsoft Excel Desktop أو Power BI Desktop أو VS Code أو Jupyter الكامل أو حزم Python المكتبية كافة. هذه برامج مستقلة لا يمكن تضمينها بأمان في صفحة متصفح عادية. يمكن بناء تكاملات API أو خادم عمل لاحقاً، مع مصادقة وعزل ونسخ احتياطي قبل استقبال بيانات حساسة.
