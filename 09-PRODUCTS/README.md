# Product Portfolio

The portfolio is pharmacy-first: medicine data quality, stock/expiry/consumption analytics, medication safety, workflow design and evidence-grounded pharmaceutical knowledge.

1. [Pharma Stock Intelligence](Pharma-Stock-Intelligence/README.md) — stock, consumption, ABC/FSN, FEFO and replenishment review.
2. [Drug Safety Signal Explorer](Drug-Safety-Explorer/README.md) — responsible public spontaneous-report exploration.
3. [Pharmacy Workflow Automator](Pharmacy-Workflow/README.md) — human-approved administrative process automation.
4. [Medicine Master Data Cleaner](Medicine-Data-Cleaner/README.md) — ingredient/strength/form/route data quality.
5. [Pharma Knowledge Copilot](Pharma-Knowledge-Copilot/README.md) — cited retrieval over curated official sources.

Excel is one analysis tool. Python, SQL, Power BI, statistics, APIs, ML, LLM/RAG, testing and pharmacy-domain knowledge are essential parallel skills.
