# Pharmacy Workflow Automator

**Problem:** Repetitive administrative reporting consumes staff time.

**MVP:** Generate a draft expiry/reorder report from an approved synthetic CSV, flag exceptions and require human approval before external action.

**Stack:** Python and CSV/Excel; GitHub Actions only for non-sensitive demo data.

Controls: input validation, audit log, error handling, preview-before-export and human sign-off. No autonomous clinical or dispensing actions.
