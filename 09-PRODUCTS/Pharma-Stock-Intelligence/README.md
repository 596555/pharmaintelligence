# Pharma Stock Intelligence

**Problem:** Pharmacy teams need visibility into stock, batch expiry and replenishment priorities.

**MVP:** Import a synthetic stock/batch CSV, validate it, calculate stock/expiry KPIs and export a review report.

**Stack:** Excel/Power Query or Python/pandas, then Power BI.

**KPIs:** units on hand, stock value (only if cost is defined), batches nearing expiry, days of cover (only if usage history exists) and potential stockout list.

Recommendations are drafts for authorized staff review. Never infer clinical substitutions or alter dispensing decisions.
