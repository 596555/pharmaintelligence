# 365-Day Roadmap — Pharmacist to AI-enabled Pharmacy Specialist

**Capacity:** 10 hours/week, approximately 520 hours/year. **Budget:** zero. **Approach:** learn a skill, apply it to a pharmacy question, test the output, document it and publish a portfolio artifact.

| Period | Technical skills | Pharmacy specialization | Evidence |
|---|---|---|---|
| Days 1–30 | Data literacy, Excel, statistics, Git basics | Medicine catalogue, units, batch/expiry concepts | Clean synthetic medicine/stock dataset and data dictionary |
| Days 31–60 | Python, CSV, pandas, validation, tests | Product/pack/unit normalization; stock quality | Tested medicine master-data validator |
| Days 61–90 | SQL, SQLite, joins, CTEs, window functions | Batch traceability, consumption and expiry queries | 20 pharmacy SQL queries and reproducible analysis |
| Days 91–135 | Power Query, Power BI, DAX, visualization | Stock, expiry, ABC/FSN and availability dashboards | Interactive inventory BI report |
| Days 136–180 | Statistics, APIs, data provenance | Pharmacovigilance, ICSR, FAERS/openFDA, MedDRA concepts | Carefully caveated public-data safety explorer |
| Days 181–225 | Process mapping, APIs, automation, CI | Receiving, stock review, recall and expiry workflows | Human-approved pharmacy workflow prototype |
| Days 226–270 | ML, time series, evaluation, explainability | Demand forecasting, expiry risk, stockout-aware evaluation | Backtested operational forecast with baseline |
| Days 271–320 | LLMs, RAG, embeddings, evaluation | Official medicine documents and terminology | Cited pharmacy knowledge assistant with abstention |
| Days 321–365 | Integration, security, testing, communication | End-to-end medication-use and pharmacy operations case | Five products, two case studies, CV and interview portfolio |

## Weekly 10-hour allocation
- 2 h: structured learning from free sources.
- 5 h: implementation against a pharmacy dataset/problem.
- 1 h: testing and error analysis.
- 1 h: pharmacy interpretation and limitations.
- 1 h: documentation, GitHub and communication.

## Role identity
Target a credible entry profile such as **Pharmacy Data Analyst / Pharmacy Informatics Associate / Healthcare Data Analyst**. Build toward specialist capability through demonstrated products; do not claim to be a clinical AI expert after introductory training.

## Graduation rule
A skill is complete only when you can explain its assumptions, reproduce its result, test edge cases, describe clinical/operational limitations and show the artifact to another person.
