# 365-Day Roadmap

**Cadence:** 10 hours/week. Suggested split: 4 hours learning, 5 hours building, 1 hour documenting/reviewing.

| Period | Focus | Evidence |
|---|---|---|
| Days 1–30 | Data literacy, spreadsheets, formulas, basic statistics | Clean synthetic pharmacy dataset + report |
| Days 31–90 | SQL, Python fundamentals, pandas, Git | SQL analysis, reproducible notebook and cleaning script |
| Days 91–180 | Pharmaceutical data, Power Query, Power BI, visualization, ML basics | Inventory dashboard + caveated public-data analysis |
| Days 181–270 | Process mapping, automation, APIs, validation and testing | Workflow prototype + medicine catalogue validator |
| Days 271–365 | Integrate, test, document, demo and prepare for jobs | Five polished products, portfolio README and case studies |

## Milestones
- **Day 30:** spreadsheet data cleaning and descriptive summary.
- **Day 90:** answer a defined question using SQL and Python.
- **Day 180:** publish a dashboard and responsible public-data analysis.
- **Day 270:** demonstrate a tested, low-risk administrative workflow.
- **Day 365:** publish five documented products and two case studies.

Do not advance based on video completion alone. Advance when the artifact runs, is understandable to another person, and documents assumptions, tests and limitations.
