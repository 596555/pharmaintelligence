# 365-Day Roadmap

**Weekly cadence:** 4 hours learning, 5 hours building, 1 hour documenting/reviewing.

| Period | Focus | Required evidence |
|---|---|---|
| Days 1–30 | Data literacy, spreadsheets, formulas, basic statistics | Clean synthetic pharmacy dataset and short report |
| Days 31–90 | SQL, Python fundamentals, pandas, Git | SQL analysis, reproducible notebook and cleaning script |
| Days 91–180 | Pharma data, Power Query, Power BI, visualization, ML basics | Inventory dashboard and caveated public-data analysis |
| Days 181–270 | Process mapping, APIs, automation, validation and tests | Workflow prototype and medicine catalogue validator |
| Days 271–365 | Integrate, test, document, demo and job preparation | Five polished products and two case studies |

## Milestones
- **Day 30:** spreadsheet cleaning and descriptive summary.
- **Day 90:** answer a defined question using SQL and Python.
- **Day 180:** publish a dashboard and responsible public-data analysis.
- **Day 270:** demonstrate a tested, low-risk administrative workflow.
- **Day 365:** publish five documented products and two case studies.

Advance only when the artifact runs, is understandable to another person, and documents assumptions, tests and limitations.
