# Working Rules

- This repository is the source of truth for project work.
- Every learning topic must produce a practical pharmacy/healthcare artifact.
- Prefer public or synthetic data; document provenance and terms.
- Use small commits with clear messages.
- Never upload secrets, API keys, patient-identifiable or confidential data.
- Make notebooks reproducible; state assumptions and dependencies.
- Separate exploratory analysis from validated conclusions.
- Add tests before calling a workflow reliable.
- Document limitations and unsafe use cases.
- Avoid paid subscriptions unless a specific need is justified.
