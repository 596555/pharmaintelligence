# Product quality gate

- [ ] Fresh clone installs using documented steps.
- [ ] Synthetic/public data provenance is stated.
- [ ] Required fields, types, ranges and duplicates are tested.
- [ ] Malformed input fails safely.
- [ ] KPI definitions and denominators are documented.
- [ ] No patient/confidential data or secrets are present.
- [ ] Clinical limitations and human-review points are explicit.
- [ ] Another person can reproduce the demo.
- [ ] Known limitations and next steps are recorded.

Any privacy breach, secret leak or unsafe clinical claim is an automatic failure.
